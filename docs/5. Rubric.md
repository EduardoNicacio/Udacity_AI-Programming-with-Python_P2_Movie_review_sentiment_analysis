# Rubric

Use this project rubric to understand and assess the project criteria.

## Load, explore, and prepare data

### Criteria

Load the train and test datasets using helper functions correctly.

### Submission Requirements

1. A helper function has been used to load the dataset
2. The loaded dataframes have the correct dimension as given in the assert statements.

### Criteria

Explore a text dataset with the help of descriptive statistics and visualizations.

### Submission Requirements

- Descriptive statistics associated to the dataset have been calculated
- At least 2 key metrics of the datasets have been visualized with proper labelling on the graphs

### Criteria

Implement a custom Dataset in Pytorch

### Submission Requirements

- The `__init__()` , `__len__()` , and `__getitiem__()` functions have been implemented according to the requirements.
- IMDBDataset objects instantiated for training data, validation data, and test data have the right lengths and data types as given in the assert statements.

## Model Definition and Training

### Criteria

Customize the architecture of the transformer model for binary classification.

### Submission Requirements

1. The `__init__()` and `__forward__()` functions of the DemoGPT class have been implemented according to the requirements.
2. Output from the DemoGPT class has the correct shape for the given dummy input as given in the assert statement.

### Criteria

Implement a function to calculate the accuracy of a model performing a binary classification task

### Submission Requirements

The function definition of the `calculate_accuracy()` function has been completed according to the requirements.

### Criteria

Implement the training loop of a transformer model for a binary classification task

### Submission Requirements

1. The training loop for the transformer model has been completed according to the requirement.
2. The model has been trained without errors.

## Industry Best Practices

### Criteria

Train a model that achieves >75% test accuracy

### Submission Requirements

1. Accuracy on the test dataset has been calculated.
2. The test accuracy is greater than 75%.

### Criteria

Create a report on the project results

### Submission Requirements

1. Project results have been summarized
2. At least 2 key takeaways have been listed

## Suggestions to Make Your Project Stand Out

- Tweak the config of the model or the training loop to achieve over 90% accuracy on the test set.
- Save the model checkpoint to the machine and provide a simple interface (in the form of a function or a class) that can load the model and perform inference on a batch of inputs.
