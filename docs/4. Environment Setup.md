# Environment Setup

## Project Environment

For this project, you will need to use Python and other related libraries. Note that you will need access to an Nvidia GPU to train the transformer model effectively. Along with that, you will need to use an IDE like VSCode or Jupyter Notebook to edit the starter notebook.

## Local Machine Instructions

You can find the requirements.txt file in the workspace. You can use that to setup your local environment.

## Workspace Instructions

The workspace given below has all the required libraries installed in it. It will open to a notebook that contains the starter code and instructions that you need to follow to complete the project.
